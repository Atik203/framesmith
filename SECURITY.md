# Security policy

Framesmith is an early-stage project. There is no guaranteed response-time or patch-time commitment.

## Reporting a vulnerability

Please do not post passwords, API keys, personal data, or an unpatched vulnerability in a public issue.
If GitHub's **Report a vulnerability** option is available on this repository, use it to send a private
report. If it is unavailable, use the contact method listed on the maintainer's
[GitHub profile](https://github.com/Atik203) to request a private reporting channel before sending sensitive
details. Do not include secrets in the initial public contact.

Include, when safe to do so:

- the affected file, feature, or version/commit;
- steps to reproduce and the potential impact;
- any safe proof of concept, with real credentials and personal data removed.

The maintainer will assess reports as time permits. Please allow an opportunity to investigate and prepare a
fix before publicly disclosing a confirmed issue. This policy does not promise a fix or a particular timeline.

## Supported versions

There are no release channels or version-specific security support guarantees yet. The latest state of the
`main` branch is the only development line, and it may change without notice.
